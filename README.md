## 🚀 Key Visual & Astrophysical Features

### 1. 🕳️ Relativistic Warping Black Hole (Event Horizon)
- **WebGL / GLSL Ray-Marching Fragment Shader**: Real-time gravitational lensing warping background spacetime according to General Relativity principles.
- **Astrophysical Anatomy**: Pure Schwarzschild shadow, Einstein photon sphere, Doppler beaming, and tilted Keplerian accretion disk.
- **Singularity Core**: Uncluttered, singular viewport floating centered in deep space.

### 2. 👨‍🚀 Interactive 3D Mini Astronaut Cursor & Spaghettification Matrix
- **3D Microgravity Inertia**: Tracks mouse momentum with `perspective(800px) rotateX(...) rotateY(...)` flight pitch, roll, and yaw banking.
- **Dynamic 3D Visor Glint**: Specular highlight on the golden visor reflects light based on the relative angle to the black hole accretion disk.
- **Relativistic Spaghettification**: Tidal gravitational shear stretches the astronaut radially along the gravitational gradient and compresses it transversely.
- **Singularity Collapse**: Disappears into the black hole center with an energetic quantum Hawking radiation matter flash.

### 3. 🌌 The "Galaxy" Panel — Revolving Andromeda Galaxy (M31)
- **High-Density Stellar Simulation**: ~14,000 active stellar and nebular bodies dynamically rendered on HTML5 Canvas with additive blending.
- **Vera Rubin Flat Galactic Rotation Curves**: Authentic logarithmic 2-arm spiral structure where orbital velocities mimic dark matter halo dynamics without winding distortion.
- **Orbiting Dwarf Galaxies**: Companion elliptical galaxies **M32** and **M110** orbiting in real-time.
- **Horizontal Academic Milestone Layout**: Space-saving dual-column grid featuring:
  - **College Level**: *ICCT Colleges Inc* — College of Engineering and Digital Technology (2023 — Present)
  - **Senior High School Level**: *DAEHAN College of Business and Technology Inc* — ICT Strand (2017 — 2018)

### 4. ⚡ The "Supernova" Panel — Revolving Neutron Star & Magnetosphere
- **Relativistic Core & Synchrotron Jets**: Incandescent blue-white thermal core ($T \approx 10^6\text{ K}$) with collimated relativistic particle jets precessing in 3D.
- **Dipolar Magnetosphere & Accretion Torus**: Dynamic 3D magnetic field loops ($r = R_0 \sin^2\theta$) and Doppler-boosted plasma debris torus.
- **Horizontal 4-Column Skill Clusters**: Streamlined competency matrix with all 28 skills calibrated to **Intermediate** status:
  - *Core Languages & Foundations*
  - *Frontend & Graphics Engineering*
  - *Backend & Distributed Systems*
  - *DevOps, Cloud & Infrastructure*

## 💻 Running Locally

To run the portfolio on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/kianrances-rgb/My-Portfolio.git

# 2. Navigate to the project directory
cd My-Portfolio

# 3. Start a local HTTP server
# Using Python:
python -m http.server 8000

# Or using Node.js:
npx serve .
```

Then open your browser and navigate to `http://localhost:8000`.
